# דרך התקומה — העתקת תוכן וניהול

היעד הפעיל הוא העתקה נאמנה של 51 עמודי האתר המעודכן, עם ניהול תוכן וסיורים לרזיאל. WordPress ו־Grow נשארים מערכות ההרשמה, התשלום, ההזמנות והטפסים הקיימות. אין פרויקט איקומרס חדש כחלק מההשקה.

## סביבת הבדיקה

https://derech-tkuma-review.22yarden22.workers.dev/

הבדיקה חסומה לאינדוקס. ה־CMS משתמש בהזדהות המשותפת, בהרשאות, בטיוטות, בהיסטוריה ובניהול מדיה. קוד התוכן החדש מוסיף כתובות וכרטיסים לפריטים מפורסמים, עם דפדוף ושמירת כתובות; פרסום תוכן אינו יוצר הרשמה או עסקה במערכת עסקית חדשה.

## גבולות מפורשים

`lib/business-scope.ts` מקפיא כניסות לנתיבי איקומרס והחלפת טפסים ניסיוניים. שינוי משתנה סביבה או פרמטר בדפדפן אינו פותח אותם. קוד ניסיוני שנשמר בעבר לא הופעל; ההרחבות החדשות נשמרו בנקודת הקפאה פרטית והוצאו מנתיב הפריסה בלי מחיקת העבודה.

ניהול המערכת המקורית: https://derech-tkuma.com/wp-admin/ . לפני מעבר יש לקבל ניתוב שממשיך לשרת את נתיבי WordPress/AJAX, עוגיות ו־nonce טרי, טפסים, Grow וניהול המקור. אין להעביר נתונים לכותב עסקי חדש או להחליף משלוחי מייל ללא צורך מוכח.

## בדיקות ופריסה

בדיקות ההשקה מתמקדות בתוכן, הרשאות, נראות, SEO, חסימת אינדוקס, גיבוי ושחזור, חיבורים קיימים והקפאת ההרחבות. בדיקות דפדפן רצות בשלב מרוכז נפרד לאחר התקנת הדפדפן. הסוויטות הניסיוניות נשמרו אך אינן תנאי להשקה.

הפריסה לבדיקה עוברת דרך GitHub ו־Cloudflare; ייצור מחייב קבלה מפורשת ופרופיל מוגן. אין לבצע שינוי דומיין או דואר מתוך בדיקת העותק.

התכנית הנוכחית: [תכנית ההעתקה והמעבר](../docs/site-code-migration-feasibility.md). החלטות וראיות תפעול פרטיות נשמרות מחוץ למאגר הציבורי.

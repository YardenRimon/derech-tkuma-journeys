# מסעות תקומה בעוטף

דף נחיתה עבור שירות **מסעות תקומה בעוטף** של מיזם [דרך התקומה](https://derech-tkuma.com).

מסעות חינוכיים בעוטף עזה לבתי ספר, מכינות, תנועות נוער, וארגונים חברתיים, חינוכיים, עסקיים וממשלתיים — כחלופה משמעותית למסעות לפולין ולסמינרים מסורתיים.

## 🌐 Live

הדף עולה אוטומטית ל-GitHub Pages:
**https://yardenrimon.github.io/derech-tkuma-journeys/**

## 📁 מבנה

```
.
├── index.html      # מבנה הדף (HTML, RTL)
├── style.css       # שפה עיצובית התואמת ל-derech-tkuma.com
├── script.js       # תפריט נייד, scroll-reveal, ולידציית טופס
└── assets/         # לוגו ותמונות אותנטיות מהשטח
```

## 🎨 שפה עיצובית

- **פלטה**: ירוק עוטף `#154332`, חול `#F7EFE1`, חמרה `#B6855B`, מרווה `#C9D4B3`
- **טיפוגרפיה**: דיסקורדיה (כותרות), polin (טקסט), כתב יד (אקצנטים)
- **חתימה צורנית**: `border-radius` א-סימטרי בסגנון האתר הראשי

## 🖥️ הרצה מקומית

```bash
python3 -m http.server 8765
# פתח: http://localhost:8765
```
